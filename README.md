# HOT PARA — React 반응형 홈페이지 시안

패러글라이딩 동호회 HOT PARA를 위한 React + Vite 홈페이지 시안입니다.

## 실행 방법
```bash
npm install
npm run dev
```
빌드: `npm run build` (출력 디렉터리 `dist`)

## 포함 기능
- 반응형 상단 메뉴
- 히어로 섹션
- 블로그형 비행 이야기 및 카테고리 필터
- 모임 참여 CTA
- 사진 갤러리

현재는 프런트엔드 시안이며, 실제 게시글·회원·사진 업로드·일정 관리는 백엔드/API 연결이 필요합니다.
